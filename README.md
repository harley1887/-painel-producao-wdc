# Painel de Produção WDC Ilhéus

Painel da produção da fábrica de Ilhéus, com acesso por login (equipe cadastrada pelo Harley).

- Os dados **não ficam neste repositório**. Eles são enviados pela página `admin.html` e só aparecem depois do login.
- **Nunca** colocar o arquivo `dados.js` aqui: este repositório é público.

Arquivos:
- `index.html`: tela de login
- `painel.html`: o painel
- `admin.html`: envio dos dados e exportação dos lançamentos (só o Harley)
- `config.js`: configuração do login
- `estilo.css`: aparência da tela de login
- `logo.js`, `nexo.js`, `banner.js`: imagens do painel
