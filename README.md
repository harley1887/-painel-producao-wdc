# Painel de Produção WDC Ilhéus

Site com login (Firebase). Este repositório não tem nenhum dado da produção.

- `index.html`: tela de login. Depois do login, busca os dados no Firebase e abre o painel.
- `painel.html`: o painel (sem dados).
- `admin.html`: página para o administrador enviar o arquivo `dados.js` ao Firebase.
- `config.js`: configuração do Firebase (não é segredo).
- `estilo.css`, `logo.js`, `nexo.js`, `banner.js`: visual.

Não coloque o arquivo `dados.js` neste repositório.
